# JumpListsView - Recent Items Stored on This PC

JumpListsView reads jump lists: files an application on this PC has opened or pinned. It is a local list. It does not reach another computer.

---

## Product Snapshot

You can see which document a program last offered in its taskbar list. That helps when you forgot a filename on your own desk. The same list on a shared login shows everyone's recent files in that Windows user. Open it only for a reason about files you are allowed to see.

A path is not an invitation. If the row points at a folder you should not browse, do not follow it. Do not post the export. Do not clear jump lists to hide that a file was opened. This page will not describe that.

## Highlights

- Recent items for apps on this PC
- Pinned items in those lists
- Paths you should treat as private
- This install only
- No need to delete the lists to finish
- An export you can skip

---

## Live Production

Use it to remember a file you opened yesterday in an app you use. Find the name, open it from the real folder if you may, and close the viewer. If you are handing the PC to someone else, the recent list is a reason to sign out of Windows, not a list to publish.

Pinned items are ones a user chose to keep. Leave another person's pins alone.

---

## Your App, Your File

Filter your attention to the program you used. The filename is a reminder. Open it from the folder you know, not by treating every path in the list as yours to browse.

---

## Setup Path

Prerequisites: This Windows user is yours, or you administer the PC and have a concrete file to find.

1. Open JumpListsView.
2. Look for the app you used.
3. Read the filename. Do not follow a path that is not yours.
4. Skip the export unless you need a private copy.
5. Close the window and sign out if the next person should not see your session.

## Who Benefits

JumpListsView fits a search for your own recent document. It does not fit snooping, a posted list of paths, or wiping history.

---

## Fixes

A file is missing from the list: the app may not have recorded it, or it was never opened here. The path does not open: you may not have access. Stop. The list shows another person: you are in their Windows user. Close it.
